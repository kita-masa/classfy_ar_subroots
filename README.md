# Classification of $SU(1,k)$ Embeddings

This program performs the root-system computations used in the accompanying paper. The output is produced directly by the search algorithm and may still contain mutually equivalent embeddings; consequently, it can contain more entries than the final classification in the paper.

## Usage

The program requires a C++20 compiler, CMake, Bash, and Graphviz. In particular, Graphviz's `dot` command is used to convert DOT files to SVG.

From the project root, run:

```sh
./scripts/build.sh
./scripts/gen_all.sh
```

The computation may take from several tens of seconds to several minutes, depending on the environment.

Generated files are written to `results/`. For each Lie algebra type, `results/<type>/svg/` contains Vogan diagrams representing the embeddings $\mathfrak{su}(1,k)\simeq \mathfrak{h}\hookrightarrow\mathfrak{g}$, while `results/<type>/associated_svg/` contains Vogan diagrams representing the associated embeddings $\mathfrak{h}^{\theta\sigma}\hookrightarrow\mathfrak{g}^{\theta\sigma}$.

In the Vogan diagrams in svg/, the labels su_0, ..., su_{k-1} correspond to the roots $\alpha_1,\ldots,\alpha_k$ of $\mathfrak{su}(1,k)$ used in the paper, respectively, while the labels Z(su)\_i represent the simple roots of $\mathfrak{c}_{\mathfrak{g}}(\mathfrak{h})$.
The label su_k corresponds to the root $\alpha_1+\alpha_2$.

The directory `results_used/` contains the output that was generated by the author and used in the paper.
